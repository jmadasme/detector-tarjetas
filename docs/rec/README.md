# rec/ — video explicativo

Este directorio contiene el video asciinema de **Detector de Tarjetas: visión clásica, sin entrenamiento** y el reproductor
que se usa en la página del proyecto.

- `detector-tarjetas.cast`: grabación original (asciicast v2).
- `detector-tarjetas.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:59. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
